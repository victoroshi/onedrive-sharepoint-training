# DEMO SECTION 1: Microsoft OneDrive

---

## D1 — Navigate to OneDrive from office.com
**Time:** ~2 minutes | **Service:** OneDrive

### What participants will learn:
How to access OneDrive from the Microsoft 365 portal — the starting point for all cloud storage.

### Steps:

**Step 1:** Open your browser and go to:
```
https://office.com
```

**Step 2:** Sign in with your Microsoft 365 work email and password.
> *[You should see the Microsoft 365 home page with a grid of colourful app tiles — Word, Excel, Teams, etc.]*

**Step 3:** Look at the left-hand sidebar or the app grid. Click the **OneDrive** tile.
> *[It looks like a light blue/white cloud icon labelled "OneDrive"]*

**Step 4:** OneDrive opens. You will see:
- **My files** — your personal cloud storage
- **Shared** — files others have shared with you
- **Recent** — files you recently opened
- **Recycle bin** — deleted files (recoverable for 93 days)

> **Trainer note:** Point out that the navigation panel on the left mirrors what you'd see in a typical File Explorer on Windows — it's intentionally familiar.

**Step 5:** Look at the top of the screen. You will see:
- A **New** button — to create files directly in OneDrive
- An **Upload** button — to upload files from your device
- A **Search** bar — to find any file instantly

✅ **Checkpoint:** Everyone should see their OneDrive with a "My files" view. Ask: "Can everyone see the OneDrive page?"

## D2 — Upload a File and Create a Folder
**Time:** ~3 minutes | **Service:** OneDrive

### What participants will learn:
How to upload a file from their device to OneDrive, and how to organise files into folders.

### Steps:

**Step 1 — Create a folder first:**

1. Click the **New** button (top-left area)
2. Select **Folder** from the dropdown menu
3. Name the folder: `Training Practice`
4. Click **Create**

> *[A new folder appears in your file list with a yellow folder icon]*

**Step 2 — Open the folder:**

1. Double-click on `Training Practice` to open it

**Step 3 — Upload a file:**

**Method A (Drag and Drop):**
1. Open File Explorer / Finder on your device
2. Locate any file (Word, PDF, image, etc.)
3. Drag the file from your device and **drop it into the OneDrive browser window**
4. Watch the upload progress bar appear briefly, then the file appears

**Method B (Upload button):**
1. Click the **Upload** button at the top of the screen
2. Select **Files**
3. Browse to any file on your device
4. Click **Open**

> *[The file appears in your Training Practice folder with its file type icon]*

**Step 4 — Verify the upload:**
- The file should now show in your folder
- Look for a **green checkmark** icon — this means the file is synced to the cloud

> **Trainer note:** Explain the status icons:
> - ☁ Blue cloud = stored online only (not downloaded locally)
> - ✓ Green checkmark = synced and available offline
> - 🔄 Circular arrows = currently syncing

✅ **Checkpoint:** Everyone should have at least one file visible inside their `Training Practice` folder.

## D3 — Share a File Using a Link
**Time:** ~3 minutes | **Service:** OneDrive

### What participants will learn:
How to share a file by generating a secure link, and how to control exactly who can access it.

### Steps:

**Step 1 — Select the file to share:**

1. Inside your `Training Practice` folder, hover over the file you just uploaded
2. A **checkbox** appears on the left — click it to select the file
3. The file row highlights in blue

**Step 2 — Open the Share menu:**

Option A: Click the **Share** button that appears in the top toolbar

Option B: Right-click the file → click **Share**

> *[A Share dialog box appears]*

**Step 3 — Configure sharing settings:**

1. At the top of the Share dialog, click **"Anyone with the link can edit"** to open the Link Settings
2. Change the audience to: **"People in [Your Organisation]"**
   > *This ensures the link only works for colleagues with your company email — not anyone on the internet*
3. Change **"Can edit"** to **"Can view"** (read-only — they cannot change anything)
4. Optionally: set an **Expiration date** (e.g. 7 days from today)
5. Click **Apply**

**Step 4 — Copy and share the link:**

1. Click **Copy link**
2. A confirmation appears: "Link copied"
3. You can now paste this link into an email, Teams chat, or WhatsApp

> **Trainer note:** Demonstrate: "Paste the link into your browser address bar and press Enter — you see the file exactly as a recipient would, with View Only access."

**Step 5 — Review who has access:**

1. Back on the file, click the **Info** button (ⓘ) on the right panel
2. Under "Has access" you can see exactly who can open the file
3. Click **Manage access** to change or remove permissions at any time

✅ **Checkpoint:** Participants should have a link copied to their clipboard and understand the difference between "Anyone" and "People in Organisation" sharing.

> **Key message:** *"This replaces the need to attach files to emails entirely. The link is 30 characters. The file could be 100MB. And everyone always opens the latest version."*

## D4 — View and Restore a Previous File Version
**Time:** ~2 minutes | **Service:** OneDrive

### What participants will learn:
OneDrive automatically saves the history of every change made to a file — and you can restore any previous version instantly.

### Steps:

**Step 1 — Open the file to make a quick change:**

1. Click on your uploaded Word/Excel file to open it in the browser (Office Online)
2. Add any text — type your name, or "Test edit for version history demo"
3. Wait 10–15 seconds (OneDrive auto-saves continuously)
4. Close the browser tab / return to OneDrive

**Step 2 — Access Version History:**

1. Back in OneDrive, right-click the file
2. Click **Version history**

> *[A Version History panel opens on the right side of the screen]*

**Step 3 — Explore versions:**

1. You will see a list of saved versions with timestamps (e.g. "Today, 2:34 PM — Modified by You")
2. Click on any older version to **preview it**
3. You can see exactly what the file looked like at that point in time

**Step 4 — Restore a previous version (optional demo):**

1. Hover over the version you want to restore
2. Click the three dots **(…)** next to it
3. Click **Restore**
4. The file reverts to that earlier state — your latest edit is saved as its own version too

> **Trainer note:** "Nothing is permanently destroyed. Even if someone accidentally deletes your entire report, you can recover it from version history within 93 days."

✅ **Checkpoint:** Everyone should see at least 2 versions listed in the panel. If only one shows, wait a minute and refresh — OneDrive batches frequent saves.

# DEMO SECTION 2: Microsoft SharePoint

---

## D5 — Navigate to Your SharePoint Team Site
**Time:** ~2 minutes | **Service:** SharePoint

### What participants will learn:
How to find and navigate a SharePoint Team Site — the shared workspace for the team.

### Steps:

**Step 1 — Access SharePoint from office.com:**

1. Return to the browser tab with **office.com**
2. In the left sidebar or app grid, click the **SharePoint** tile
   > *[It has a dark blue/teal S-like icon]*
3. SharePoint opens showing:
   - **Featured Sites** — sites your organisation has highlighted
   - **Frequent sites** — sites you visit most often
   - **Recent** — sites and pages you recently visited

**Step 2 — Open your Team Site:**

**If your trainer has provided a SharePoint URL:**
1. Paste the URL directly into your browser address bar
2. Press Enter

**If accessing from Microsoft Teams (alternative path):**
1. Open Microsoft Teams
2. Click on any **Team channel**
3. Click the **Files** tab at the top
4. Click **Open in SharePoint** in the toolbar
   > *[This opens the exact same library in your browser — Teams and SharePoint are one and the same]*

**Step 3 — Explore the Team Site homepage:**

A typical SharePoint Team Site has:
- **Top navigation bar** — links to key areas (Documents, News, Pages, etc.)
- **News section** — team announcements and updates
- **Quick links** — shortcuts to frequently used tools
- **Recent documents** — files the team has recently worked on
- **Activity feed** — who changed what and when

> **Trainer note:** "This is what the team's 'homepage' looks like. Think of it as your department's internal website. Your IT or team manager controls what appears here."

✅ **Checkpoint:** Everyone should be looking at a SharePoint Team Site — either the shared training site or their own team site.

---

## D6 — Upload a File to a SharePoint Document Library
**Time:** ~3 minutes | **Service:** SharePoint

### What participants will learn:
How to upload files to the shared Document Library — the team's central file store.

### Steps:

**Step 1 — Navigate to Documents:**

1. In the SharePoint site, look for **Documents** or **Document Library** in the top navigation or left sidebar
2. Click it to open the library

> *[You see a list of folders and files that belong to the entire team — not just you]*

**Step 2 — Understand the library structure:**

A Document Library looks and feels like a folder on your PC, but:
- Every file is accessible by everyone with site permissions
- All changes are tracked automatically
- Files can be co-authored simultaneously
- Metadata columns (Department, Status, etc.) can be added

**Step 3 — Create a folder for your demo:**

1. Click **New** → **Folder**
2. Name it: `[Your Name] Training Files`
3. Click **Create**

**Step 4 — Upload a file:**

**Method A (Drag and Drop):**
1. Open File Explorer on your PC
2. Drag a file directly into the browser window showing the SharePoint library
3. The file uploads and appears immediately

**Method B (Upload button):**
1. Click **Upload** → **Files**
2. Select a file from your device
3. Click **Open**

**Step 5 — Verify and explore:**

1. Click on the file to open it in Office Online (browser)
2. Notice the URL bar shows a SharePoint address — this is the file's permanent home
3. Close the file browser tab — return to the library

> **Trainer note:** "If a colleague opens this same file at the same time, you will both see each other's name in a coloured flag in the document. That is co-authoring in action."

✅ **Checkpoint:** Each participant should have a file visible inside their named folder in the SharePoint Document Library.

---

## D7 — Sync a SharePoint Library to Your Desktop
**Time:** ~3 minutes | **Service:** Both (OneDrive + SharePoint)

### What participants will learn:
The most powerful integration feature: making a SharePoint team library appear as a normal folder on your PC desktop — powered by OneDrive.

### Steps:

**Step 1 — Start the Sync:**

1. In the SharePoint Document Library, look for the **Sync** button in the top toolbar
   > *[It has a circular arrow icon — usually between "New" and "Export"]*
2. Click **Sync**

**Step 2 — Handle the browser prompt:**

1. A browser dialog may ask: *"This site is trying to open Microsoft OneDrive"*
2. Click **Open** or **Allow**
   > *[The OneDrive desktop app opens and begins syncing]*
   > *[If OneDrive is not installed, you will be prompted to download it first — available at onedrive.com]*

**Step 3 — Watch it appear on your PC:**

1. Open **File Explorer** (Windows) or **Finder** (Mac)
2. In the left sidebar, look for a new entry — it will be named after your organisation, e.g.:
   - `[Organisation Name] – SharePoint`
   - or the team site name
3. Open it — you see the same folders and files that are in the SharePoint library

**Step 4 — Test the two-way sync:**

1. In File Explorer, open the synced folder
2. Copy any file from your desktop into this folder
3. Switch back to the SharePoint browser tab and refresh the page
4. **The file appears in SharePoint immediately** — it synced automatically

5. Now from the browser, rename a file (right-click → Rename)
6. Switch to File Explorer — the file name has changed there too

> **Trainer note:** "This is the magic of the integration. Your team's shared SharePoint library is now just another folder on your PC. You don't need to open a browser to work with shared files."

**Step 5 — Understand the sync icons:**

Look at the files in File Explorer — you will see small icons:
- ✓ Green checkmark — synced and available offline
- ☁ Blue cloud — stored online only (click to download)
- 🔄 Spinning arrows — currently syncing
- ⚠ Yellow warning — sync conflict (two people edited simultaneously — OneDrive will help you resolve it)

✅ **Checkpoint:** Everyone should see the SharePoint library appearing as a folder in their File Explorer/Finder. This is the key "aha" moment — the two services are truly one system.

# BONUS WALKTHROUGH: Co-authoring in Real Time (Optional — if time allows)

**Time:** ~3 minutes | **Service:** Both

This walkthrough demonstrates real-time collaborative editing — multiple people working on the same document simultaneously.

### Steps:

**Step 1:** Ask one participant to open a Word document stored in the SharePoint Document Library (from D6 above).

**Step 2:** Ask a second participant (or the trainer) to open the **same document** at the same time from their device.

**Step 3:** Both participants start typing in different parts of the document.

**What to observe:**
- A coloured flag with the other person's name appears near their cursor
- Changes appear in near real-time (within 1–2 seconds)
- No "file is locked" message — SharePoint allows unlimited simultaneous editors
- The document auto-saves every few seconds

**Step 4:** One participant adds a comment (Insert → Comment → type a message → @mention the other person).

The mentioned person receives an email notification with a direct link to the comment.

> **Key takeaway:** "No more emailing versions back and forth. No more 'Document_v3_FINAL_JohnEdits_reviewed.docx'. One file. Multiple editors. Real time."

# TROUBLESHOOTING: Common Issues & Solutions

| Issue | Likely Cause | Solution |
|-------|-------------|----------|
| "Access denied" when opening a SharePoint site | You don't have permission | Contact the Site Owner or IT and request access |
| File won't upload (grey out) | File is open on your PC | Close the file first, then upload |
| Sync not starting | OneDrive app not installed | Download from onedrive.com and install |
| Shared link says "Sorry, this link isn't available" | Link expired or was revoked | Ask the sender to generate a new link |
| Can't find a file you uploaded | It may be in the wrong folder | Use the Search bar at the top of OneDrive/SharePoint |
| Co-authoring not working | File may be open in desktop app in non-collaborative mode | Close and reopen in Office Online (browser) |
| Sync shows yellow warning ⚠ | Two people saved conflicting changes | OneDrive will show you both versions — you choose which to keep |
| "File is locked for editing" | Someone has the file checked out | Ask them to check it back in, or wait for them to close it |

# GLOSSARY

| Term | Definition |
|------|-----------|
| **OneDrive** | Microsoft's personal cloud storage service. 1 TB of space included with Microsoft 365. |
| **SharePoint** | Microsoft's team collaboration and document management platform. Used for shared files, intranets, and team sites. |
| **Cloud storage** | Files stored on Microsoft's servers (not just your PC) — accessible from any internet-connected device. |
| **Sync** | The process of keeping files identical between your PC (local) and the cloud (online) — automatically. |
| **Document Library** | A folder-like container in SharePoint that stores team files with version tracking and permission controls. |
| **Version History** | A log of all saved changes to a file — you can view or restore any previous version. |
| **Co-authoring** | Multiple people editing the same document simultaneously, seeing each other's changes in real time. |
| **Sharing link** | A URL generated for a specific file that you send to others instead of attaching the file to an email. |
| **Site Owner** | The person responsible for managing a SharePoint site's settings, layout, and user permissions. |
| **Member** | A SharePoint user who can add, edit, and delete content on a site (but not manage settings). |
| **Visitor** | A SharePoint user with read-only access — they can view files but cannot edit or upload. |
| **Permissions** | Rules that control who can see or edit files, folders, or SharePoint sites. |
| **Microsoft 365** | Microsoft's subscription suite of productivity apps including Word, Excel, Teams, OneDrive, and SharePoint. |
| **Teams channel** | A workspace within Microsoft Teams where a group communicates — its Files tab is a SharePoint library. |
| **Recycle Bin** | A recovery area where deleted files are held for 93 days before permanent deletion. |
